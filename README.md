# AIIDE

AIIDE is an early-development, local-first desktop coding workspace. Its long-term vision is to help developers use local AI models to work with real repositories while keeping changes controlled and reviewable.

The planned workflow is **Open → Ask → Inspect → Edit → Review → Test → Commit**. The current milestone supports opening a folder, inspecting its file tree and Git state, and basic local chat through Ollama. Chat does not read project files or use tools. Repository-aware AI and editing are planned for later milestones.

See [PROJECT.md](PROJECT.md) for the detailed specification and roadmap.
